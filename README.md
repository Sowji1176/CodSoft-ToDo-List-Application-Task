## 📌 Overview

The **TO-DO LIST APPLICATION** is a responsive task management web application designed to help users organize and manage their daily activities efficiently.

The application allows users to create, edit, delete, search, filter, and track tasks while storing task data locally in the browser using Local Storage.

## 🎯 Objective

The objective of this project is to create an intuitive and responsive task management application with practical task organization features and persistent local data storage.

## ✨ Features

### Core Features

- Add new tasks with validation
- Edit existing tasks
- Delete unwanted tasks
- Mark tasks as completed or pending
- Persistent task storage using Local Storage
- Display total tasks
- Display completed tasks
- Display pending tasks
- Search tasks
- Filter tasks

### Bonus Features

- Task categories
- Priority levels
- Due dates
- Overdue task detection
- Dark mode support
- Persistent dark mode preference
- Responsive design
- Empty-state messages
- Delete confirmation
- Smooth UI interactions

## 📋 Task Management

Each task can contain:

- Task title
- Description
- Category
- Priority
- Due date
- Completion status
- Creation date

Users can easily update the task status by marking tasks as completed or pending.

## 🏷️ Task Categories

The application supports multiple task categories:

- Work
- Personal
- Study
- Shopping
- Other

This helps users organize tasks according to different areas of their daily activities.

## ⚡ Priority Levels

Tasks can be assigned different priority levels:

- Low
- Medium
- High

This allows users to identify important tasks more easily.

## 📅 Due Dates

Users can assign due dates to tasks.

The application can display useful states such as:

- Due Today
- Due Tomorrow
- Overdue
- Completed

This helps users keep track of important deadlines.

## 🔍 Search & Filtering

The application includes a real-time search feature that can search through task information.

Available filters include:

- All
- Pending
- Completed
- High Priority

Search and filtering work together to help users quickly find specific tasks.

## 💾 Local Storage

Task data is stored using the browser's **Local Storage API**.

This allows tasks to remain available after:

- Refreshing the page
- Closing and reopening the browser

The selected dark/light mode preference is also stored locally.

## 📊 Task Statistics

The dashboard dynamically displays:

- Total Tasks
- Completed Tasks
- Pending Tasks

Statistics automatically update whenever tasks are added, edited, deleted, or completed.

## 🌙 Dark Mode

The application includes a dark mode feature that allows users to switch between light and dark themes.

The selected theme preference is saved using Local Storage so it remains active after refreshing the page.

## 📱 Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile devices

The layout, task cards, forms, search controls, and filters adapt to smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
